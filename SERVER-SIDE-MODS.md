# Contrast SMP Forge server mods

Install the 46 JARs in [Server-Side-Mods-Forge-1.20.1.zip](https://github.com/jxttomm-coder/ContrastSMP-Updates/releases/latest/download/Server-Side-Mods-Forge-1.20.1.zip) on the Forge 47.4.28 server (Minecraft 1.20.1, Java 17). Stop the server and back up the existing `mods` folder before replacing its contents.

The SHA-256 verified list is in `server-mods.json`. The three client-only exclusions remain AppleSkin, Entity Model Features, and Entity Texture Features. Dynamic Light 0.3 and Runes 1.3.2 are included on both client and server. Runes bundles Bundle API, so no separate JAR is needed. Create 6.0.8 embeds Flywheel and Ponder.

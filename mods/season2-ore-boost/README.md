# Contrast SMP Season 2 Ore Boost

Forge 1.20.1 server and client mod. Install the jar on both sides before creating or exploring new chunks.

All vanilla ore placement attempt counts are multiplied by 5. Emerald is multiplied by 7. This includes coal, iron, copper, gold, redstone, lapis, diamond, nether gold, quartz, and ancient debris. Large counts are split into multiple legal count placements to stay within Minecraft's 256 maximum per placement. Existing chunks are not regenerated.

Build with Java 17:

```powershell
.\gradlew.bat build
```

The jar is written to `build/libs/contrast_s2_ores-1.0.1.jar`.

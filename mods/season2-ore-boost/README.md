# Contrast SMP Season 2 Ore Boost

Forge 1.20.1 server and client mod. Install the jar on both sides before creating or exploring new chunks.

All vanilla ore placement counts are multiplied by 5. Emerald ore is multiplied by 7. This includes coal, iron, copper, gold, redstone, lapis, diamond, nether gold, quartz, and ancient debris. Existing chunks are not regenerated.

Build with Java 17:

```powershell
.\gradlew.bat build
```

The jar is written to `build/libs/contrast_s2_ores-1.0.0.jar`.

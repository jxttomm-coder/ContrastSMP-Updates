# Contrast SMP Season 2 Underground Control

Forge 1.20.1 server and client mod. Install the jar on both sides before creating or exploring new chunks.

It disables vanilla ancient cities, buried treasure, mineshafts, trail ruins, Nether fossils, dungeons, and amethyst geodes. Strongholds remain enabled. A Trial Chambers backport can generate because this mod does not change its structure set. Existing chunks are not regenerated.

The supplied No Caves and No More Amethyst Geodes mods are also included in the server manifest.

Build with Java 17:

```powershell
.\gradlew.bat build
```

The jar is written to `build/libs/contrast_s2_underground-1.0.0.jar`.
